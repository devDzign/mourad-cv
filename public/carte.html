      Exporter la carte en image

      Pour Teams : « Copier l'image » puis Cmd + V dans la conversation, ou envoyez le PNG. Pour une carte animée : « GIF animé », puis glissez le fichier dans la conversation. Le SVG reste net à toutes les tailles (documents, présentations).

      Aperçu de la carte telle qu'elle apparaîtra dans un email

      Cliquez sur « Copier pour un email », puis collez (Cmd + V) dans le corps d'un message Gmail, Outlook ou Apple Mail. Vous pouvez aussi la coller dans votre signature d'email.
